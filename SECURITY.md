# Security Policy

## Supported versions

Kalah currently receives security updates for the latest public release.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Older versions | No |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub Issues.

Use GitHub Private Vulnerability Reporting instead:

https://github.com/vlwork/Kalah/security/advisories/new

When submitting a report, please include as much relevant information as possible, such as:

- the affected version and platform;
- a clear description of the vulnerability;
- steps required to reproduce the issue;
- the potential security impact;
- logs, screenshots, or proof-of-concept material where appropriate.

Please avoid publicly disclosing vulnerability details before the issue has been investigated and, where necessary, a fix has been prepared.

Kalah is developed by Researcher Universe Labs.
